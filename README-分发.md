# FARS Dashboard — 分发说明

给拿到这个包的人看的。

---

## 一、这是什么

一个**本地运行**的论文写作看板。核心能力：

- 左侧是**文件列表**：导入 docx / pdf / md / txt 文档，按章节切成可编辑论文
- 中间是**正文编辑器**：在任意位置单击插入新段落，拖动决定字数
- 长按十字会弹出**写作方向扇形菜单**（FAN HUD），按上下文给出可检验的写作方向
- 右键文件名可以**重命名 / 导出 Word / Markdown / 纯文本 / 复制 / 删除**
- 右侧有**文献与数据面板**：直接检索论文（OpenAlex / Crossref / arXiv）和公开数据集
  （World Bank / Kaggle / figshare），**下载会做完整性校验**，确认真的落到磁盘
- 点已下载的文献 → **弹出 PDF**；点数据 → **弹出 CSV 表格 / HTML**，可直接在界面里看
- **一篇论文一个文件夹**：文献在 `01_文献/`、数据在 `02_数据/`、图表在 `03_图表/`、分析在 `04_分析/`
- 右侧**审查栏**每条问题都有**「一键修改」**按钮，不用自己找位置改
- 右上角 **⚙ 设置** 里可以换模型、填 API Key、改端口

所有数据都在你自己的机器上，服务只监听本机（默认 `127.0.0.1`）。

## 二、怎么打开

1. 解压 `FARS Dashboard.zip`
2. 把 `FARS Dashboard.app` 拖到「应用程序」文件夹
3. **双击打开**

> ⚠️ macOS 会提示「无法打开，因为无法验证开发者」——
> 这是因为没有苹果官方签名，不是文件有问题。
> **解决办法（选一个）：**
> - 右键点 app → 选「打开」→ 弹窗里再点「打开」
> - 或者 系统设置 → 隐私与安全性 → 往下滚 → 点「仍要打开」
>
> 首次启动会弹一个「正在启动」提示框，等它几秒，浏览器自动打开。

---

## 三、第一步：配置模型

打开后点右上角 **⚙ 设置**：

1. **预设供应商** 选一个（DeepSeek / MiniMax / Kimi / 通义千问 / OpenAI / Claude / 自定义）
2. 填你的 **API Key** → 点「测试连接」验证 → 点「保存模型设置」

> **API Key 存在哪？**
> 存在 **macOS 钥匙串**（Keychain），**不写进配置文件**，也不会随包分发。
> 别人拿到这个包，用的是他自己的 Key。
>
> 如果你的机器不让写钥匙串，可以改用环境变量：
> `export FARS_API_KEY=sk-xxxx`

**支持的协议**：OpenAI 兼容（DeepSeek / Kimi / 通义 / OpenAI / 任何兼容端点）
和 Anthropic 兼容（MiniMax / Claude）。

## 四、数据在哪

```
~/Library/Application Support/FARS Dashboard/
├── papers/          论文实体（JSON）
├── imports/         导入的原始文件
├── config.json      模型配置（**不含 Key**）
└── filemeta.json    导入/改名/删除记录
```

### 每篇论文一个文件夹

在 `papers/` 目录下，**每篇论文对应一个独立文件夹**，里面按用途分四层：

```
papers/
├── <论文编号>__<主题>.json      ← 论文真源（正文、状态、审查结果）
└── <论文编号>_<主题>/           ← 这篇论文的资料目录
    ├── 01_文献/                ← 下载的 PDF + sources.json 清单
    │   ├── 某作者_2025_标题.pdf
    │   └── sources.json         ← 每篇的作者/年份/期刊/DOI/页数
    ├── 02_数据/                ← 下载的数据集 + data_sources.json
    ├── 03_图表/                ← 生成的图表
    └── 04_分析/                ← 分析产物
```

> 那个 `__` 的 `.json` 是**真源**，改它才是改论文；文件夹里放的是**资料**。
> 两者一一对应，删掉资料文件夹不会伤到正文。

- 首次运行会放一份**虚构的示例论文**（DEMO01）进去，方便你看清怎么用
- 左栏右键 → 删除 可以把它移除
- 想完全清空：删掉整个 `FARS Dashboard` 文件夹即可

**导入的论文、写的正文、API Key 都只在你本机**，不会上传到任何地方
（除了你主动调用模型时，请求会发给你配置的模型服务商）。

## 五、文献与数据怎么用

右栏「**文献与数据**」面板，三个标签页：

| 标签 | 作用 |
|------|------|
| **文献 PDF** | 检索论文，下载并**校验**后存进 `01_文献/` |
| **数据集** | 检索公开数据集，下载并**校验**后存进 `02_数据/` |
| **已下载** | 列出已下载的全部文献和数据，**点开就能看** |

### 检索通道

- 文献：**OpenAlex → Crossref → arXiv**（逐级降级，任意一个有结果就用它）
- 数据：**World Bank → Kaggle → figshare**

> 网络受限时某个通道会失败，面板会**明确告诉你哪个通道没通、为什么**，
> 不会假装成功。

### 下载是「校验过的」

文献必须同时满足四条才算成功，**否则不留假文件**：

1. 文件头是 `%PDF`
2. 文件尾有 `%%EOF`
3. `pypdf` 能解析且页数 > 0
4. PDF 首页标题与检索标题**确实对得上**（Jaccard 相似度匹配）

数据则会按**文件魔数**判断类型：ZIP 会自动解压并**取真正的数据 CSV**
（World Bank 的压缩包里混着只有几百字节的「指标元数据」，不能拿那个冒充数据）。

### 点开就能看

- 文献 → 「**查看 PDF**」在界面里内嵌渲染；也可「用系统打开」交给预览器
- 数据 → 「**查看表格**」解析成可滚动的表格（World Bank CSV 开头有前言行，会自动跳过定位真表头）
- HTML 数据 → 直接在界面里渲染

> 选中论文之后才能下载 —— 东西要落到**那篇论文自己的文件夹**里。

## 六、遇到问题？导出诊断日志（内测必读）

如果出现**崩溃、报错、界面卡住、点了没反应、数据不对**这类问题，
请导出诊断日志发给开发者 —— 有日志基本能直接定位问题，没有日志只能靠猜。

### 怎么导出

1. 点右上角 **⚙ 设置**
2. 滑到最下面，找到 **「诊断日志」** 区块
3. 点 **「导出诊断日志」**
4. 会下载一个 `fars-diagnostics-日期.zip`
5. **把这个 zip 原样发给开发者**（不用解压）

### 日志里有什么

| 文件 | 内容 |
|---|---|
| `app.log` | 服务端日志：接口异常、启动信息、导出记录 |
| `client.log` | **前端 JS 报错**：报错信息、堆栈、出错位置、URL、操作轨迹 |
| `requests.log` | 接口请求流水：方法、路径、状态码 |
| `env.json` | 运行环境：系统版本、Python 版本、端口、状态目录 |
| `summary.txt` | 人看的摘要：错误次数和最近几条错误 |

其中 `client.log` 会带上你**报错前点了什么**的操作轨迹，
这能帮开发者复现「点了哪里之后出的问题」。

### 关于隐私

- **不会记录 API Key、密码、令牌** —— 写入前已脱敏，导出时还会再脱敏一次
- **不会记录论文正文** —— 长文本会被截断
- 日志只存在**你自己机器上**（`~/Library/Application Support/FARS Dashboard/logs/`），
  只有你点「导出」才会打包出来
- 导出的 zip 里**不包含你的论文文件**

### 如果日志里没东西

说明这次运行没有捕获到错误。可以先**重现一次问题**，再点导出。

## 七、常见问题

**Q：双击没反应 / 提示无法验证开发者**
→ 见「二、怎么打开」。

**Q：浏览器没自动打开**
→ 手动访问 `http://127.0.0.1:8790/`。

**Q：端口被占用**
→ 应用会自动往后找一个空闲端口（8790 → 8791 → …），
也可以在设置里手动改。

**Q：生成内容时转圈的橙色圆圈**
→ 那是「正在生成」的指示，正常。生成结束/失败/取消会停。

**Q：拖动插入的字数对不上**
→ 拖动路径按你拖出的字数严格对齐；长按路径**不限字数**（按写作要求优先）。
两种路径是分开的。

**Q：导入 PDF 报「需要 OCR」**
→ 扫描件没有文字层，需要先自己 OCR 成 docx/txt 再导入。

**Q：怎么完全重置**
→ 设置页最下面「恢复默认设置」，或直接删掉整个状态目录。
